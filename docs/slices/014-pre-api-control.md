# S10 — bounded mock dispatch, failures and pre-API readiness

[Task](../../tasks/task-S10-PRE-API.md) · [mock control](../../src/sca/mock_run.py) · [tests](../../tests/test_mock_run.py) · [R1 experiment and DoD audit](../reviews/pre-api-readiness.md).

The new mock control combines the unchanged usage_gate and request_ledger. Each HTTP attempt is one **controlled gate step**, including auxiliary/retry attempts; ledger CLI steps remain separate. The runnable demo independently observes three actual HTTP requests versus two declared CLI steps and refuses the fourth attempt. Unknown cost under a configured soft cap stops after the first observed attempt; the existing post-step gate does not guarantee the first call's cost. Time is checked before beginning and again before dispatch, not as cancellation of an in-flight response. Explicit mock permission denial produces no pending attempt or network request; it is not repository policy evaluation.

`begin` creates pending metadata before network; `dispatch` sends it once. Caller checkpoints between them when studying crash boundaries. Checkpoint fields are schema_version=1, mock_only=true, ledger, limits, elapsed_ms. `reopen` validates schema, frozen identity/limits, recorded relationships/provenance and accumulated active time; it does not send HTTP. A pending/failed/incomplete latest attempt requires an explicit retry with a fresh ID linked to that attempt. Prior attempts remain visible, with missing usage UNKNOWN. A completed run can begin an explicitly requested new attempt within remaining limits.

The demo/tests round-trip JSON through a temporary file outside the target repo. This is metadata recovery evidence, **not** durable production transactions, checkpoint integrity attestation, workspace restoration or V2 reliable resume. Offline downtime is not accumulated as active elapsed time. Restored metadata is caller-supplied observation, not permission or proof of provider activity. Concurrent/multi-process use is outside this single-run experiment.

Checks cover denial, step/time/unknown-price boundaries, delayed dispatch, pending/crash/HTTP/transport/protocol failure reopen, fresh explicit retries, duplicate IDs, retry of completed attempt refusal, frozen identity/limits/schema, retained counters/time and detached exports. The existing source/test hashes are compared with the pre-work baseline; no working source, old test or fixture is modified.
